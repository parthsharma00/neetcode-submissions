# NeetCode Solutions

My solutions to the [NeetCode](https://neetcode.io) interview-prep problem set, in Python. I'm working through the NeetCode roadmap (arrays & hashing → two pointers → sliding window → trees → graphs → DP) alongside my CS degree, and keeping every attempt here, not just the final one, so the progression from brute force to optimal stays visible.

Every accepted submission syncs here automatically from NeetCode.

## Layout

```
Data Structures & Algorithms/
  <problem-slug>/
    submission-0.py   ← first attempt
    submission-N.py   ← later, usually faster, attempts
```
